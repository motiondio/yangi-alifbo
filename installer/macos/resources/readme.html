Oʻrnatishdan keyin

  1. Ilova oʻzi ochiladi. Belgisi – menyu satrida (ekranning yuqori oʻng qismida) yashil ö. Dock'da koʻrinmaydi.
  2. macOS ikkita ruxsat soʻraydi: System Settings → Privacy & Security → Accessibility va Input Monitoring roʻyxatlarida «Yangi Alifbo» ni yoqing. Ruxsatsiz macOS klaviatura dasturlariga ishlashga yoʻl qoʻymaydi.
  3. Ruxsat berilgach dastur oʻzi ishga tushadi (macOS «Quit & Reopen» desa – bosing).

Boshqaruv

  • Control+Option+U – yoqish / oʻchirish (masalan, inglizcha yozayotganda).
  • Almashgandan keyin darhol Backspace – asl yozuv qaytadi (ş → sh).
  • s'h deb yozsangiz ş boʻlmaydi: Is'hoq → Ishoq.
  • Menyu satridagi belgi → Sozlamalar… – dasturlar roʻyxati, avtomatik ishga tushish va boshqalar.
