После установки

  1. Программа откроется сама. Её значок — зелёная ö в строке меню (вверху справа). В Dock её нет.
  2. macOS запросит два разрешения: в «Системные настройки» → «Конфиденциальность и безопасность» → «Универсальный доступ» и «Мониторинг ввода» включите «Yangi Alifbo». Без них macOS не позволяет программам работать с клавиатурой.
  3. После выдачи разрешений программа один раз перезапустится и начнёт работать (если macOS предложит «Завершить и снова открыть» — нажмите).

Управление

  • Control+Option+U — включить / выключить (например, когда пишете по-английски).
  • Backspace сразу после замены — возвращает исходное написание (ş → sh).
  • Если написать s'h, ş не получится: Is'hoq → Ishoq.
  • Значок в строке меню → «Настройки…» — язык, список программ, статистика, автозапуск и другое.
